# 02. 패시브 스킬 트리 & 혈통 각성 설계 (Passive Tree & Ascendancy)

이 문서는 **혈월의 야성(가칭)**의 빌드 자유도를 책임지는 **공유 패시브 스킬 트리(본능의 성좌)**와 **혈통 각성(전직)** 시스템의 구조 및 데이터 스키마를 정의합니다.

---

## 1. 패시브 스킬 트리 전체 구조

PoE1의 방사형 6방향 원형 트리를 채택하여, 모든 종족이 하나의 거대한 트리를 공유하되 **시작 위치(Origin)**만 다르게 배치합니다.

```text
               [12시: INT]
           올빼미 / 여우 (마법·ES)
         /                        \
  [10시: STR+INT]            [2시: DEX+INT]
  염소 / 들소 (토템·대지)     까마귀 / 박쥐 (독·덫)
        |                          |
  [8시: STR]                 [4시: DEX]
  곰 / 멧돼지 (방어·출혈)     늑대 / 표범 (치명·투사체)
         \                        /
               [6시: STR+DEX]
            사자 / 호랑이 (전투·함성)
```

- **총 노드 수 목표**:
  - **초기 MVP (v0.1)**: 순수 스탯 3종족(곰/늑대/올빼미) 중심의 고밀도 **`120 ~ 150개` 노드**로 시작하여 핵심 빌드 루프를 검증
  - **정식/확장**: 복합 종족 추가 및 클러스터 확장을 통해 약 `600 ~ 800개` 노드로 확장
- **포인트 획득**: 레벨업당 `1 포인트` + 주요 퀘스트 보상 `12~16 포인트` (최대 레벨 100 기준 약 115 포인트).
- **스킬 초기화**: 퀘스트 보상 또는 드롭 화폐(**망각의 혈석 / 회개의 서**)를 통해 노드 단위 초기화 가능.

## 2. 노드 등급 및 역할

1. **소형 노드 (Minor Node)**
   - 경로를 연결하는 기본 노드.
   - 예: `+10 근력`, `+10% 물리 피해 증가`, `+6% 최대 생명력 증가`, `+8% 화염 저항`.
2. **주요 노드 (Notable Node)**
   - 작은 클러스터의 끝에 위치하며, 해당 테마의 강력한 보너스를 제공.
   - 예:
     - **「굶주린 발톱」**: 공격 피해 `+24% 증가`, 적 처치 시 생명력 `+15` 회복.
     - **「혈월의 은총」**: 최대 에너지 보호막 `+20% 증가`, 에너지 보호막 재충전 시작 속도 `15%` 빨라짐.
3. **숙련 노드 (Mastery Node)** *(클러스터 중앙)*
   - 특정 테마(예: 출혈, 활, 방패, 소환수)의 **주요 노드를 1개 이상 찍으면** 중앙의 숙련 슬롯이 활성화되어, 해당 테마의 고유 유틸리티 옵션 목록 중 1개를 선택 가능.
   - *장점*: 트리 크기를 무리하게 키우지 않고도 빌드에 특화된 옵션을 깔끔하게 제공.
4. **핵심 노드 (Apex Node)**
   - 트리의 외곽에 배치되며, **게임의 규칙을 바꾸는 강력한 장점 + 치명적인 페널티**를 동시에 부여.

---

## 3. 핵심 노드 (Apex Node) 10종 설계 (초안)

| 이름 | 위치 성향 | 효과 (장점 + 페널티) |
| :--- | :--- | :--- |
| **1. 피의 갈증** *(Bloodthirst)* | 8시 (STR) | **마나를 제거**합니다. 모든 스킬이 마나 대신 **생명력**을 소모하며(잔여 생명력 이상 소모 시 발동 불가), **오라(Aura)는 최대 생명력을 점유(Reserve)**합니다. 소모한 생명력이 클수록 피해량이 최대 `30% 증폭`됩니다. |
| **2. 야수의 직감** *(Feral Precision)* | 8시~6시 (STR/DEX) | 공격이 **절대 빗나가지 않습니다(명중 100%)**. 대신 **치명타를 입힐 수 없습니다**. |
| **3. 불굴의 모피** *(Iron Pelt)* | 8시~10시 (STR/INT) | 베이스 회피력을 모두 **방어도**로 전환합니다. 대신 회피력이 `0`으로 고정됩니다. *(단, `% 회피 증가`와 `% 방어도 증가`는 합산 적용되며 이중 적용되지 않음)* |
| **4. 순수한 혼돈** *(Pure Chaos)* | 12시 (INT) | 최대 생명력이 **`1`로 고정**됩니다. 대신 **혼돈 피해에 완전 면역**이 됩니다. (극단적 ES 빌드용) |
| **5. 그림자 걸음** *(Shadowstep)* | 4시 (DEX) | **주문 피해를 회피**할 수 있게 되지만, 방어도와 에너지 보호막이 `50% 감폭`됩니다. |
| **6. 고독한 늑대** *(Lone Wolf)* | 4시~2시 (DEX/INT) | **소환수를 소환할 수 없습니다**. 대신 자신이 받는 모든 피해 `10% 감폭`, 이동 속도 `+15% 증가`. |
| **7. 선조의 결속** *(Ancestral Tether)* | 10시 (STR/INT) | 최대 소환 가능 **토템 +1개**. 대신 캐릭터 본인이 직접 가하는 스킬 피해(공격/주문 타격)가 `0`이 됩니다. |
| **8. 원소의 균형** *(Elemental Balance)* | 12시~2시 (INT/DEX) | 한 원소로 적을 타격하면 **적의** 해당 원소 저항이 `+25%` 올라가는 대신, **적의** 다른 두 원소 저항이 `-35%` 감소합니다. |
| **9. 폭주의 심장** *(Heart of Frenzy)* | 6시 (STR/DEX) | 이동하지 않고 제자리에 서 있는 동안 매초 공격 속도 `10% 증폭`(최대 5중첩). 이동 시 즉시 초기화되며 이동 속도가 `15% 감소`. |
| **10. 역병의 숙주** *(Plague Host)* | 2시 (DEX/INT) | **독이 1중첩으로 제한**되지만, 독 피해량이 `120% 증폭`되고 지속 시간이 `2배`로 증가합니다. |

## 4. 혈통 각성 (Bloodline) 시스템 *(v0.2 도입)*

각 종족은 4단계 시련(1차 Act 2 · 2차 Act 3 · 3차 엔드게임 Tier 1+ · 4차 엔드게임 Tier 10+)을 통과할 때마다 **각성 포인트 2점(총 8점)**을 얻어, 종족 전용 미니 트리를 해금합니다.

### 4.1 설계 예시: 늑대 수인 (DEX)
- **전직 A: 그림자 송곳니 (Shadowfang — 치명타 & 출혈/은신)**
  - `2점`: 치명타 확률 `+100% 증가` / 치명타 시 적에게 100% 확률로 출혈 부여
  - `4점`: 출혈 중인 적 처치 시 `2초`간 은신(적의 타겟팅 우선순위 하락 및 이동 속도 +20%)
  - `6점`: 치명타 배율 `+50%`, 출혈 피해가 치명타 배율의 `50%`만큼 추가 증폭
  - `8점`: 은신 상태에서 첫 타격 시 무조건 치명타 적중 및 출혈 지속 시간 2배
- **전직 B: 질풍 사냥꾼 (Gale Hunter — 투사체 & 기동성)**
  - `2점`: 모든 투사체 스킬에 **투사체 +2개** 추가
  - `4점`: 이동 중 공격 속도 감소 페널티 무시, 회피 성공 시 격분(Frenzy) 충전 획득
  - `6점`: 투사체가 적에게 **1회 관통(Pierce)** 또는 **연쇄(Chain)**하며, 남은 거리에 따라 피해량 최대 `30% 증폭`
  - `8점`: 최근 `4초`간 이동 거리에 비례해 공격 속도 및 이동 속도 최대 `+25%` 추가 증가

*(다른 종족들의 혈통 각성 상세 스펙은 v0.2 확장 시 별도 문서로 추가)*

## 5. 구현용 그래프 데이터 스키마 (JSON)

실제 게임 엔진(Godot, TypeScript 등)에서 패시브 트리를 렌더링하고, **시작 지점으로부터 연결된 노드만 찍을 수 있는지(BFS/DFS) 검증**하기 위한 표준 데이터 구조입니다.

```json
{
  "version": "0.1.0",
  "nodes": [
    {
      "id": "node_wolf_start",
      "name": "늑대 부족의 기원",
      "type": "START",
      "race": "WOLF",
      "position": { "x": 420, "y": 240 },
      "icon": "icon_start_wolf",
      "stats": [],
      "adjacentIds": ["node_dex_01", "node_dex_02"]
    },
    {
      "id": "node_dex_01",
      "name": "날카로운 감각",
      "type": "MINOR",
      "position": { "x": 460, "y": 210 },
      "icon": "icon_dex_minor",
      "stats": [
        { "stat": "DEX", "modType": "FLAT", "value": 10 },
        { "stat": "ACCURACY", "modType": "INCREASED", "value": 10 }
      ],
      "adjacentIds": ["node_wolf_start", "node_notable_claw"]
    },
    {
      "id": "node_apex_lone_wolf",
      "name": "고독한 늑대",
      "type": "APEX",
      "position": { "x": 680, "y": 120 },
      "icon": "icon_apex_lone_wolf",
      "description": "소환수를 소환할 수 없지만, 받는 피해가 감폭되고 이동 속도가 증가합니다.",
      "stats": [
        { "stat": "DISABLE_MINIONS", "modType": "FLAG", "value": 1 },
        { "stat": "DAMAGE_TAKEN", "modType": "LESS", "value": 10 },
        { "stat": "MOVEMENT_SPEED", "modType": "INCREASED", "value": 15 }
      ],
      "adjacentIds": ["node_dex_14"]
    }
  ]
}
```

### 그래프 유효성 검증 규칙
1. **노드 획득(Allocate)**: 대상 노드의 `adjacentIds` 중 최소 1개가 이미 활성화된 상태여야 함.
2. **노드 환불(Refund)**: 대상 노드를 비활성화한 뒤, 시작 노드(`START`)에서 BFS를 돌려 현재 활성화된 모든 다른 노드에 여전히 도달할 수 있는지 확인(고립된 섬 발생 방지).
