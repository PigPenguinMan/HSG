# 캐릭터 화풍 샘플 비교

게임 에셋(`assets/sprites/`)에 반영하기 전에 화풍을 비교하는 폴더입니다. `.gdignore`가 있어서 Godot이 이 폴더를 임포트하지 않습니다.

## 공통 조건 (늑대 플레이어)
- 크기: **64×32 PNG**, 32×32 프레임 2장을 가로로 붙인 걷기 스트립, 배경 투명 (지금 `wolf_player.png`와 같은 형식)
- 화풍: 2.5등신 치비, 굵고 어두운 1px 외곽선, 단색 면 위주(음영 최소), 크림색 얼굴에 1×2 세로 점 눈과 볼터치, 발밑 반투명 그림자
- 머리 폭 약 18px (너무 크지 않게)
- 캐릭터: 회색 늑대 수인. 뾰족한 귀(안쪽 분홍), 붉은 스카프, 짙은 보라 망토, 꼬리
- 특정 게임의 캐릭터를 따라 그리지 않고, 화풍 특징만 참고
