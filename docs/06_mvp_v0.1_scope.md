# 06. 인디 MVP (v0.1) 스코프 및 개발 로드맵

이 문서는 **혈월의 야성(가칭)**의 첫 번째 플레이 가능 프로토타입(**v0.1**)에서 "게임이 실제로 재미있는가"를 가장 빠르게 검증하기 위해 스코프를 엄격히 제한하고, 개발 순서를 정의합니다.

---

## 1. v0.1 완료 기준 (Definition of Done)

> **목표**: 약 **30분 플레이**로 **「사냥 → 아이템 드롭/장착/크래프팅 → 패시브 찍기 → 액트 1 보스 1체 처치」** 코어 루프가 매끄럽게 돌아가고, 같은 레벨에서 **최소 2가지 서로 다른 빌드**(예: *근접 출혈 늑대* vs *원거리 투사체 늑대*)가 확실히 체감되는 것.

## 3. 개발 순서 (Architecture-First Roadmap)

GDD의 Phase 2였던 스탯/아이템 계산 로직을 **가장 먼저(Phase 0)** 분리 구현하여, 수식 오류를 단위 테스트로 원천 차단합니다.

1. **Phase 0: 엔진 비의존 코어 라이브러리 (`core/`) + 단위 테스트**
   - `StatAggregator`: 패시브 노드 + 장비 + 버프 모디파이어 합산기
   - `DamagePipeline`: `01_combat_and_stats.md` 기준 피해/방어/출혈 계산 및 극단 빌드 상한 테스트
   - `PassiveTreeGraph`: JSON 로드, BFS 연결성 검증 및 노드 환불 검증
   - `ItemGenerator & Crafter`: 가중치 어픽스 추첨, 시드 기반 RNG, 5종 화폐 크래프팅
2. **Phase 1: 전투 프로토타입 (엔진 레이어)**
   - 탑뷰 이동, 마우스/키보드 공격(5종 액티브 + 4종 보조 룬 태그 적용)
   - 몬스터 스폰/AI(추적/공격), 히트박스/피격 피드백, 아이템 드롭
3. **Phase 2: RPG UI 연동**
   - 슬롯형(1×1) 인벤토리 + 장비 장착 + 화폐 크래프팅 클릭 적용
   - 패시브 스킬 트리 줌/팬 UI + 실시간 스탯창 반영
4. **Phase 3: 액트 1 수직 슬라이스 완성**
   - 거점(야영지) ↔ 필드 2개 ↔ 보스방(`철갑 브룬` 텔레그래프 패턴) 연결 및 30분 플레이 테스트
